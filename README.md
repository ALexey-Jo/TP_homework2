# TP_homework2
Консольное приложение, которое позволяет создавать блюда, добавлять их в "рецепты", маштабировать порции и генерировать список покупок.

Автор проекта - Дементьев Алексей Витальевич ББИ2501

# Ingredient
Класс Ingredient представляет собой базу нашего проекта - хранит информацию о каждом продукте, его количестве и единицах измерения.
# Recipe 
Класс Recipe представляет собой рецепт одного блюда. Он нужен для объединения название блюда с набором ингредиентов, которые для него требуются, а также он предоставляет методы для работы с этими ингредиентами. 

# DietaryRecipe
Класс DietaryRecipe представляет собой рецепт с указанием диетической категории, например ("не веган", "с рафом на грудном", "кето")



# Test_recipes
Тесты для Класса Ingredient проверяют, что все атрибуты правильно оптимизируются, проверяют, что строка возвращается в правильном формате. Тажке, что два ингредиента с одинаковым названием и единицей измерения считаются одинаковыми. Также, что два ингредиента с разными названиями считаются неразными и, что два ингредиента с разными единицами измерения считаются неравными.
