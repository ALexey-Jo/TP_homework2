# TP_homework2
Консольное приложение, которое позволяет создавать блюда, добавлять их в "рецепты", маштабировать порции и генерировать список покупок.

Автор проекта - Дементьев Алексей Витальевич ББИ2501
# Ingredient
Класс Ingredient представляет собой базу нашего проекта - хранит информацию о каждом продукте, его количестве и единицах измерения.
#Recipe 
Класс Recipe представляет собой рецепт одного блюда. Он нужен для объединения название блюда с набором ингредиентов, которые для него требуются, а также он предоставляет методы для работы с этими ингридиентами.
